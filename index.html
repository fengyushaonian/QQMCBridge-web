Features

一套插件，串起群与服

这是原插件 QQMCBridge 的魔改增强版（QQMCBridge+）：在保留原版聊天互通、进服通知、群命令等全部能力的基础上，扩展了双端子插件生态（JS mods + Python pymods）、HTML 图卡渲染、多服务器聚合与本地 Web 管理面板。

群服双向互通

QQ 群消息实时广播进服务器，MC 聊天 / 进出服 / 死亡事件自动推送到群，自定义消息格式。

腾讯官方协议

官方机器人 API 全量封装：群消息、富媒体图片 / 视频 / 文件、禁言、入群审批、指令面板，稳定合规。

多服务器聚合

一个网关同时桥接主服 + 子服，群消息发往所有服务器，各服消息汇聚回群，「查服」一条命令看全服。

JS 子插件生态

BDS 端 mods 动态加载：猜数字、群管理、自定义命令随手扩展，即改即用，无需改主插件。

Python 子插件

pymods 标准框架：manifest + main.py 固定结构，ctx.api 直达全部官方 API，优先级调度、后台任务、事件钩子。

HTML 图卡渲染

自绘图协议与 HTML 模板双通道，Edge 无头截图出图：帮助图卡、在线人数、玩家信息、服务器状态一目了然。

本地 Web 管理面板

浏览器打开即用：多服状态、远程执行、互通日志、可视化配置编辑器，保存后网关热重载，无需重启。

远程执行指令

OpenID 白名单授权 + 危险指令黑名单双重防护，QQ 群里也能安全地向服务器下发控制台指令。

Architecture

群 → 网关 → 服务器

轻量三层架构：Python 网关负责 QQ 官方协议与图卡渲染，BDS 端 LSE 插件负责游戏内事件与指令，二者通过本地 HTTP 双向通信。

Deploy

三步部署，即刻互通

需要一台装了 LiteLoaderBDS（LSE）的基岩版服务器，和一台能联网的机器运行 Python 网关（可与服务器同机）。

1

安装插件

将 QQMCBridge/ 复制到 plugins/ 目录，修改 config.json 中的群 OpenID 与机器人凭证。

2

启动网关

pip install requests websockets 后运行 python qq_mc_gateway.py，连接官方 WebSocket 事件通道。

3

开始使用

在群里发「帮助」查看命令；浏览器打开 http://127.0.0.1:8080 进入本地 Web 管理面板。
